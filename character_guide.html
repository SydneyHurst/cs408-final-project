Character Guide

Because sometimes you have too many

See all characters here:

Edit, Delete, or create a character here:

Characters all have the following: A ID (preferably unique to the character), a Name, a Status (this indicates health), a EXP total, and a rank. The AWS table also has room for items however this is not in use for this site.

In a actual use case, I would set the status as a dropdown of specific health statuses (for example: Healthy, Sick, Injured, etc). The same goes for ranks, I would have also made ranks calculate themselves based on the EXP total.

This idea (specifically of characters) was based largely on: https://www.kukuri-arpg.com/masterlist

The site above (and all like it) are made from a framework called lorekeeper. This is a framework ive worked with and inspired this project. If i had infinite time I would have found a way to add character images as seen above.
