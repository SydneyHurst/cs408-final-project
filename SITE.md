# How to run 
Using a local host such as xampp or an extension in Visual Studio Code, start the local server. Open the local host page in a tab on your browser starting from the index page.

# Site Features
- Home page with information
- Navigation that leads to each major page
- A character masterlist page that loads all characters currently listed
- A page to:
    - edit an existing character
    - delete an existing character
    - create a new character
- An EXP roller
     - Simple functionality to show concept
- An Item roller
    - Rolls common, uncommon, or rare items
- A example of a guide page (EXP)

# Database
The database by default uses AWS (as specified by the project). However the simple data involved could make it possible to swap to a mySQL data table instead (with a decent amount of modifications).
